# sot reference

The `sot` binary is the source of truth for the Kadena Chainweb ecosystem.
Run `sot --help` to see what it offers.

This folder will contain a snapshot of the sot schema and reference
data for the version of the bundle you have.

If you need the live data, install the sot binary:

    brew tap <org>/tap
    brew install sot
    sot sync
